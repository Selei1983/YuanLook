# 私有部署版

此分支强制私有访问，没有匿名展示开关。需要重新构建并部署此分支的服务端和管理前端；原来的官方 `latest` 镜像不包含这些改动。

- 未登录打开首页、服务器详情、监控页或管理页，服务端跳转到 `/admin/login`。
- 服务器、标签、历史指标、最新指标、网卡、服务监控及 Logo 读取接口要求有效登录；无效或过期凭证返回 401。
- 旧数据即使仍标记为 `public`，也不能匿名读取。新增探针及监控默认 `private`，后台不再提供匿名可见选项。
- 密码登录成功后，服务端设置 HttpOnly、SameSite=Lax 的会话 Cookie，HTTPS 下附加 Secure。其有效期与现有 JWT 一致。
- Cookie 仅用于页面、主题资源和只读看板 API；管理操作继续要求原有 Bearer JWT 或管理 API Key。退出登录清除 Cookie。
- 私有页面和数据响应禁止缓存。登录页及管理前端静态文件仍可匿名加载。工作区模式不启用第三方 OAuth。
- 登录方式配置及 `/api/config` 的站点品牌/主题元数据保持公开，以便渲染登录页；不包含主机或监控记录。
- 探针版本查询保持公开；安装脚本和二进制下载必须携带所属工作区有效的探针密钥，WebSocket 探针注册继续走原有 API Key 校验，不要求浏览器登录。

升级后请重新登录一次以建立页面会话。反向代理应正确传递 HTTPS 协议信息，且不要缓存私有页面或数据接口。

本次沿用原有 JWT 有效期与退出语义，没有增加服务端 token 撤销列表。退出会清除当前浏览器 Cookie，已复制的 JWT 仍按原有规则有效至到期。

## 验证

运行：`go test ./internal/... ./pkg/agent/...`；前端：在 `web` 目录运行 `npm ci`、`npm run build`。
